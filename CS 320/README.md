Now I'm going to reflect on some of what I've learned in this course:

How can I ensure that my code, program, or software is functional and secure?

What I've learned from this class is that the best way to ensure my code is functional or secure is to do a lot of different types of tests on it to ensure everything is working as it should be. It is also vital to take the approriate time when writing code to make sure their are no minor mistakes and that it is being run frequently to make sure everything is still working. Lastly, making sure there is a high test coverage percentage ensures that a lot of the aspects of the program are being tested which will lead to better results when the program is completed.

How do I interpret user needs and incorporate them into a program?

When writing the code it is important to approach it from the perspective of a user because they are ultimately the ones who will be using the software. If the software is hard for them to navigate of it doesn't work properly then they won't want to use it meaning the software will not make money and will likely die off. By reading designs, writing the approriate code, testing that code and using the product, I can get an idea of what the user would want and make changes as warranted ot provide the user with the best product.

How do I approach designing software?

The first step to desgining software is figuring out what the user wants, from there various designs are drafted up to show a rough draft of the software. After a rough draft is created then the program is coded based on the desgins and goes through a process of testing while it is being coded and once the producted reaches the end of developement. This behavior of continuosly testing and coding software is what leads to the best products as opposed to doing a lot of coding then testing it at the end, as once mistakes are found at the end it can lead to greater costs and time spent trying to fix it.
