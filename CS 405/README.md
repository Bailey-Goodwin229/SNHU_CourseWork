# CS 405: Secure Coding Portfolio

Welcome to my portfolio repository for CS 405: Secure Coding. This project serves as a showcase of my ability to identify vulnerabilities, implement defensive programming strategies, and establish robust security policies to protect software applications.

## Course Artifacts

*   **Project One: Security Policy** – A comprehensive security policy identifying system vulnerabilities, assessing risks, and outlining industry-standard mitigation protocols.
*   **Project Two: Vulnerability Remediation Presentation** – A technical presentation detailing security gaps discovered during code analysis and the strategies used to remediate them.
*   **Source Code (ZIP)** – Zipped packages containing the functional source code, secure implementations, and remediation refactors.
*   **Portfolio Journal Reflection** – A professional reflection document detailing my approach to secure software design and the critical insights gained throughout the course.

## Core Competencies Demonstrated
*   Vulnerability identification and remediation (OWASP Top 10)
*   Defensive programming practices
*   Secure software architecture and policy design
