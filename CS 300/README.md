In this class I learned about varying data structures and algorithms for those data structures, we had weekly assignments that focused on creating and implementing different data structures in C++. These assignments wouold take the information from monthly sales, parse through the data, upload the data in the appropriate structure, and allow the user to do different options such as load course, display course, sort course, add course or remove course. The data structures we looked at were vectors, linked lists, hash tables, and binary search trees, we then learned about Big-O notatation along with the Big-O notation for each of these structures. 

For the projects we worked on developing our own program using one of these data structures, the program took college course data, parsed through it, added it to a data structure of our choosing, and allowed the user to display the course with prerequisites or to look up an individual course. In project 1, I wrote the pseudocode for all of these functions and did a Big-O analysis on all of the functions line-by-line to see the efficiency of each function and the overall data structure. Finally, I did a comparison betwwen all of these functions based on Big-O notation and wrote an analysis of this data along with a recommendation of a data structure to be used. For the second part of the project I coded all of the functuions for the data structure I chose which was a binary search tree and created an application from start to finish in C++.
